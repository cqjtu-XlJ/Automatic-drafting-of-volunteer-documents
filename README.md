# 志愿活动材料自动撰写脚本

## 功能简介

本脚本可根据xlsx数据源自动生成以下志愿活动材料：

1. **志愿者名单汇总表** (Word) - 横向纸张，支持拆分单元格显示多个服务记录
2. **志愿服务活动时长申报表** (Word) - 活动基本信息、子活动汇总、审核意见
3. **志愿服务活动总结** (Word) - 使用方正仿宋字体的活动总结文档

## ✨ AI 智能生成

支持接入大语言模型（LLM），根据活动名称自动生成个性化的活动内容：
- **默认支持**：智谱AI GLM-4-Flash（完全免费）
- **可选支持**：DeepSeek、通义千问、月之暗面 Kimi、小米 MIMO、火山引擎 Doubao
- **智能降级**：AI 调用失败时自动使用静态模板

## 环境要求

- Python 3.8+
- 依赖包：python-docx, openpyxl, openai, pyyaml

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 配置 AI（可选）

如需使用 AI 生成内容，请编辑 `config.yaml` 文件，填入 API Key：

```yaml
llm:
  enabled: true
  provider: zhipu  # 默认使用智谱AI
  zhipu:
    api_key: "你的API Key"  # 从 https://open.bigmodel.cn 获取
```

### 2. 运行脚本

```bash
python generate_materials.py
```

### 3. 按提示输入信息

脚本会要求输入以下信息：
- **选择xlsx文件**：输入编号或直接输入文件路径
- **活动名称**：如"雷锋月志愿活动"
- **受益人类型**：如"校园内学生"
- **输出目录**：留空使用默认目录（脚本目录下的output文件夹）
- **选择AI提供商**：如已配置API Key，可选择使用AI生成内容

### 4. 自动生成

脚本会自动：
- 读取xlsx数据源
- 计算活动实施时间（从最早日期到最晚日期）
- 识别活动类型并生成相应内容（AI或静态模板）
- 生成三份材料并自动打开输出目录

## 输入文件格式（xlsx）

### 基本要求

- 文件格式：`.xlsx`（Excel 2007+）
- 第1行为表头
- 第2行起为数据行
- 支持合并单元格（姓名和学号列可留空，自动继承上一行的值）

### 支持的列格式

脚本支持多种列名格式，会自动识别以下列：

| 列序号 | 列名（支持多种） | 说明 |
|--------|------------------|------|
| 第1列 | 姓名 | 志愿者姓名 |
| 第2列 | 学号 | 志愿者学号 |
| 第3列 | 服务内容 | 志愿服务内容描述 |
| 第4列 | 服务时间/时间段 | 服务时间（支持多种格式） |
| 第5列 | 总时长/总时长(h) | 服务时长（可选，为空时自动计算） |

### 支持的时间格式

| 格式 | 示例 |
|------|------|
| 年月日 时分-时分 | 2026年3月27日 13:00-14:00 |
| 年-月-日 时分-时分 | 2026-03-27 13:00-14:00 |
| 年.月.日 时分-时分 | 2026.3.27 13:00-14:00 |
| 年/月/日 时分-时分 | 2026/3/27 13:00-14:00 |

### 支持的时长格式

| 格式 | 示例 |
|------|------|
| 数字+h | 5h、5.5h |
| 纯数字 | 5、5.5 |

### 示例格式

| 姓名 | 学号 | 服务内容 | 服务时间 | 总时长 |
|------|------|----------|----------|--------|
| 张三 | 632507070607 | 活动现场布置 | 2026年3月27日 13:00-14:00 | 1h |
|      |      | 活动现场管理 | 2026年3月27日 14:00-17:30 | 3.5h |
| 李四 | 632507100216 | 志愿服务签到 | 2026-03-27 13:00-14:00 | 1h |
|      |      | 活动场地清扫 | 2026-03-27 17:00-18:00 | 1h |

## 输出文件格式

### 1. 志愿者名单汇总表（横向Word文档）

- **纸张方向**：横向
- **字体**：宋体五号（10.5pt）
- **表头**：序号、姓名、学号、服务内容、服务时间、本项时长(h)、总时长(h)
- **特点**：
  - 每页重复表头行
  - 同一人的多项服务通过合并单元格显示
  - 总时长为该志愿者所有服务时长的简单求和

### 2. 志愿服务活动时长申报表（Word文档）

分为两个表格：

**表格一：活动基本信息**
- 一、活动基本信息
  - 活动名称
  - 活动类型（8类，默认勾选"校园公益服务"）
  - 受益人：类型及数量
  - 活动实施时间（自动从xlsx计算）
  - 活动开展单位
- 二、活动详细信息
  - 活动内容（包含：内容概述、社会问题、产生原因、必要性、服务对象、预计成效）

**表格二：子活动信息**
- 具体活动、子活动名称、活动时间、活动内容、志愿者人数、单次活动服务时长
- 三、审核意见
  - 申请单位承诺
  - 志工部审批意见

### 3. 志愿服务活动总结（Word文档）

- **字体**：方正仿宋_GBK
- **内容**：
  - 标题：信息学院学生会{活动名称}总结
  - 正文：活动开展时间、志愿者人数、志愿时长、活动概述
  - 活动成效

## 智能功能

### 活动类型自动识别

脚本会根据活动名称自动识别活动类型，并生成相应的内容：

| 活动类型 | 关键词 |
|----------|--------|
| 学雷锋 | 雷锋 |
| 环保 | 环保、绿色、生态 |
| 敬老 | 敬老、老人、养老 |
| 支教 | 支教、教育、助学 |
| 社区 | 社区、服务 |
| 通用 | 其他活动 |

### 活动内容自动生成

根据识别的活动类型，自动生成以下内容：
- 内容概述
- 社会问题
- 产生原因
- 必要性（包含7个"有利于"排比句）
- 服务对象（用户输入）
- 预计成效（系统自动填写）

### 活动时间自动计算

从xlsx文件中提取所有日期，自动计算：
- 最早日期 → 活动开始时间
- 最晚日期 → 活动结束时间

## 注意事项

1. xlsx文件支持多种列名格式，脚本会自动识别
2. 如果时长列为空，脚本会根据服务时间自动计算
3. 活动实施时间会自动从xlsx中的日期计算，无需手动输入
4. 活动内容（社会问题、产生原因等）会根据活动名称自动生成
5. 生成完成后会自动打开输出目录
6. 如果文件被占用（如Word未关闭），请先关闭文件再重新生成
7. AI 生成失败时会自动使用静态模板，不影响正常使用
